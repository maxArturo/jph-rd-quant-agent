## Codebase Patterns
- Python-only repo (>=3.10). "Typecheck passes" means the Python typechecker (pyright), not TypeScript.
- Quality gate: `make check` = ruff + pyright + pytest (use it before every commit).
- Credentials: never in code or .env — bare HTTP calls through the OneCLI proxy (HTTPS_PROXY + CA cert); management API at http://127.0.0.1:10254.
- Proxied calls from scripts: `onecli run --agent <identifier> -- curl ...`; banner on stderr, command stdout clean. See ops/CLAUDE.md for onecli CLI gotchas (UUID vs identifier, set-secrets replaces list).
- All services bind 127.0.0.1; human-facing UIs exposed via tailnet-only `tailscale serve` only.
- LLM calls go through LiteLLM under `onecli run` (placeholder keys OK — proxy overrides headers). claude-sonnet-5 rejects temperature!=1; JSON mode may return ```json fences. See research/CLAUDE.md.
- NEVER run a test path that provisions GPU droplets: ConversationCore.gpu stays None-default; only app.py wires the real GpuBackend (2026-08-06 incident). Mock doctl in all snapshot/watchdog tests.
- PRD source for this run: tasks/prd-loop-hardening.md (its US-001..US-022 map onto the finer-grained US-001..US-030 in prd.json; the PRD file is authoritative for intent and config values).
- Deploy gap: after changing orchestrator/ code, `systemctl --user restart rdq-orchestrator` or the bot runs stale code. Same for any long-running unit you modify.
